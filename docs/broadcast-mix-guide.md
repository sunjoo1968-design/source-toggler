# Camera MIX Controller 1.3.3 사용 안내

제작자: **SunjooAn** · 버전: **1.3.3**
주력 파일은 `camera-mix-controller.lua` 하나입니다. 이전 분기 배포 파일과 2.7 계열 설치본을 대치합니다.

1. OBS 도구 → 스크립트에서 이전 두 등록 항목을 제거하고 `camera-mix-controller.lua`를 추가하세요. 파일 교체만으로 실행 중인 Lua가 자동 종료되지는 않습니다. 개인 설정 가져오기 파일은 공개 배포에 포함하지 않습니다.
2. **설정 완료 / 전체 적용**을 한 번 실행하세요. 기존 그룹과 추가 항목을 재사용하며 출력에 새 MIX 처리를 연결합니다. 전체 적용은 카메라 1로 바뀝니다.
3. 글로벌 옵션에서 **MIX**와 원하는 시간을 선택하고 카메라를 전환하세요. CUT도 그대로 사용할 수 있습니다.

ME2 이후의 MIX는 두 그룹을 동시에 투명하게 만드는 방식 대신, 각 카메라의 배치를 포함한 화면을 하나의 OBS Fade로 혼합합니다. 동일 영역의 중간 밝기 저하를 방지하며, 서로 다른 위치/크기의 영상도 각 영역에서 정상적으로 혼합합니다.

카메라 배치는 기존 `ME2 Camera Inputs`의 각 그룹에서 계속 편집하세요. 그룹 자체의 위치/크기/회전/자르기도 반영됩니다. 원본 소스나 그룹 안의 장식은 그대로 공유합니다. 카메라 그룹 외의 공통 자막·배경은 `ME2 SUB Output`에서 카메라 MIX 위/아래에 배치하세요.

출력 장면에는 표시되는 `ME2 Camera MIX`와 숨겨진 원래 `ME2 Camera Inputs` 연결이 있습니다. 숨겨진 연결은 저장/재로드 때 기존 배치를 복원하기 위해 유지하므로 삭제하지 마세요. 투명 캔버스나 기준 소스가 추가되는 것은 아닙니다. 내부 혼합 화면은 장면 목록에 나타나지 않습니다.

공통 자막은 출력 장면에서 MIX보다 위에 두세요. 카메라별 그룹 안의 자막은 해당 카메라와 함께 혼합됩니다.

스크립트를 다시 불러오면 내부 MIX를 자동 재구성합니다. 스크립트를 제거하면 원래 입력 장면 출력을 복원합니다. 실행 중인 실제 OBS의 저장/재시작은 자동 수행하지 않았습니다. 새 출력의 미리보기와 재로드 상태를 확인한 뒤 방송에 사용하세요.

1.3.3부터 종료 시 ME별 마지막 카메라를 저장하고 OBS 장면 로드가 완료되면 자동 복원합니다. 준비될 때까지 재시도하며 시작 중 누른 카메라 선택은 복원 뒤 실행합니다. 공통 모드·시간과 배치는 유지합니다. 종료 시 MIX 중이었다면 도착 카메라로 복원하고 중간 Fade를 재생하지 않습니다. 재시작 때문에 전체 적용을 누를 필요는 없습니다. 전체 적용은 입력 변경/초기 설정에만 사용하며 카메라 1로 전환합니다.
