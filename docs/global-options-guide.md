# Camera MIX Controller 1.3.3 글로벌 옵션

제작자: **SunjooAn** · 버전: **1.3.3**
주력 파일은 `camera-mix-controller.lua` 하나입니다. 이전 분기 이름과 2.7 계열 설치본을 대치합니다. 기존 파일을 같은 경로에서 업데이트하면 카메라 설정과 단축키를 유지합니다. 개인 설정 가져오기 파일은 공개 배포에 포함하지 않습니다.

MIX는 배치 포함 화면을 하나의 Fade로 혼합하는 방식으로 개선되었습니다. [1.3.0 사용 안내](broadcast-mix-guide.md)를 참고하세요.

## 기본 이름
| 항목 | 기본 이름 |
|---|---|
| ME1 출력 장면 | ME1 PGM Output |
| ME1 내부 전환 소스 | ME1 PGM Camera MIX |
| ME2 출력 장면 | ME2 SUB Output |
| ME2 입력 장면 | ME2 Camera Inputs |
| ME2 cam1 그룹 | ME2-cam1 |
| ME3 출력/입력 | ME3 SUB Output / ME3 Camera Inputs |

원본 카메라 소스 이름은 바꾸지 않습니다. 그 소스를 담는 그룹 이름을 `ME이름-원본소스이름`으로 붙입니다. 장면 입력도 동일합니다. 입력을 바꾸면 같은 그룹 객체의 주 입력과 표시 이름만 바뀌며 배치/추가 항목은 유지됩니다.

## 사용 순서
1. OBS 도구 → 스크립트에서 해당 파일 새로고침.
2. **카메라·화면 설정 열기** 체크.
3. **글로벌 옵션 — 이름 / 전환 타입 / 시간**에서 각 ME 이름을 입력하세요. 예: ME2를 `하단`으로 변경.
4. 출력/입력 장면 이름을 비우면 `하단 SUB Output`, `하단 Camera Inputs`처럼 자동 생성합니다. 직접 입력하면 해당 이름을 사용합니다. 그룹은 `하단-cam1`처럼 표시됩니다.
5. 기존 배치와 카메라 선택을 그대로 두고 이름만 변경하려면 **이름만 적용 (배치·카메라 선택 유지)** 클릭.
6. 카메라 입력까지 변경했다면 **설정 완료 / 전체 적용** 클릭. 이 버튼은 카메라 1로 전환합니다.

전체 적용은 반복 실행할 수 있습니다. 이미 생성된 동일 출력과 그룹을 재사용하며, 입력 변경은 주 입력만 갱신합니다. 기존 배치와 추가 자막은 유지됩니다.

새 설정의 기본 전환 타입은 **CUT**, MIX 시간은 300ms입니다. 기존에 저장한 MIX/CUT 선택과 시간은 유지합니다. 타입과 시간은 모든 ME에 공통 적용됩니다.

기존 `ME2 Simple Output`, `ME2 Simple Camera Inputs`, `ME2-SIMPLE-CAM1`은 이름 적용 시 같은 객체를 재사용해 변경합니다. 자막/위치/추가 장면을 다시 만들 필요가 없습니다. 이름 적용 버튼은 카메라 표시 상태를 변경하지 않습니다.

이미 같은 이름의 다른 장면이 있으면 일괄 이름 변경을 거절하고 로그에 충돌 이름을 표시합니다. 특히 기존 2.7의 `ME2 Camera Inputs`가 있으면 글로벌 옵션의 입력 장면 이름에 다른 이름을 지정하세요. 기존 장면을 덮어쓰거나 자동 삭제하지 않습니다. 원본 소스 이름은 그대로 유지하세요.

현재 방송 OBS를 자동 재로드하거나 조작하지 않았습니다. 새 이름 적용은 사용자가 위 버튼을 눌러 수행합니다.
