# Camera MIX Hybrid 계획

제작자 SunjooAn. 기존 Controller 1.3.4를 보존하고 별도 Hybrid 개발판을 만듭니다.

목표는 OBS 스튜디오 모드의 소스 복제에서 Preview의 카메라 선택·배치 변경을 PGM과 분리하는 것입니다. Lua는 설정·단축키·전환 제어를 맡고 native 출력은 복제 시 선택 장면/배치를 보존합니다. 기존 탈리·현장 OBS 실행 상태를 변경하지 않습니다.

완료 기준: 별도 파일·기본 출력명·단축키 이름 공간, ME1/ME2 복제 후 화면 유지, 외부 자막 보존, 반복 복제 자원 회수, Lua 연동 및 재실행 복원 검증, Windows 개발판 패키지와 사용 안내 제공.

카메라 장치 자체의 공유 여부는 OBS 소스 플래그를 따릅니다. 복제된 장면의 탈리 원본 대응은 별도 호환 작업 대상으로 기록합니다. 기존 현장 설정을 자동 가져오지 않으며 새로운 장면 모음에서 시험합니다.
